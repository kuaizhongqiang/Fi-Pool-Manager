# 概念定义

> 阶段：概念定义 — 明确核心概念及其关系，不涉及技术选型与实现细节。
> 对应数据模型：`Data.cs`

## 概念清单

### 1. 股池（Pool）

一个**命名后的股票集合**。

- 有名称、描述、创建时间
- 包含多只股票（通过股票代码关联）
- 可对池子整体进行分析，产出池级别的分析与信号
- 同一只股票可存在于多个股池中

### 2. 股票（Stock）

A 股个股的基础信息。

- 核心标识：**六位代码 + 名称**
- 记录最新价（当前价）

### 3. 公开免费股票数据（DailyInfo）

**日线行情数据（OHLCV）**，从公开免费数据源获取。

- 每只股票每个交易日一条记录
- 包含：开盘价、最高价、最低价、收盘价、成交量
- 频率：日级，盘后更新

### 4. 小服务器可以负担的数据分析（DailyAnalysisReport）

**不依赖 LLM 的本地轻量计算**，基于 DailyInfo 产出结构化分析。

- 基础统计：涨跌幅、振幅、换手率、量比
- 技术指标：MA、MACD、RSI、KDJ、Bollinger Bands
- 信号标记：金叉、超买超卖、放量异动
- 保留文本摘要字段

### 5. LLM 分析报告（FinalReport）

**LLM 综合多角色分析后产出的最终结论**。

- 引用原始数据报告（DailyAnalysisReport）
- 引用多角色分析结果（AnalysisRoler[]）
- 输出最终综合报告文本

### 6. 多轮多角色报告解析（AnalysisRoler）

**多个预设角色对同一标的进行多轮分析与辩论**。

预设角色：
- 技术分析师 — 走势、形态、量价、技术指标
- 基本面分析师 — 估值、财务、行业
- 舆情分析师 — 市场情绪、消息面解读
- 风险控制官 — 风险、下行空间、流动性

每个角色产出独立的分析文本，最终由 LLM 合成。

### 7. 向量模型检索

**基于语义相似度的检索层**，解决以下问题：

- 60 天原始数据无法一次性全部发给 LLM（token 爆炸）
- 需要从大量分析报告中检索最相关的部分

应用方式：对 DailyAnalysisReport 和 FinalReport 做向量化存储，查询时通过语义检索召回最相关内容，作为 LLM 分析的上下文。

数据规模估算：不是大数据量，小服务器可负担。

### 8. 数据储存

存储所有概念实体的数据，包含：

- 内存态：表现为 C# 数据模型（Data.cs）
- 持久化：技术选型后确定存储方案

## 补充概念

### 9. LLM 推理服务

分析报告依赖 LLM 进行多角色分析、辩论及结论生成。

- 主推理模型：运行在本地（LM Studio），受本地硬件资源限制
- 因此需要严格控制上下文长度，不能无限制塞数据
- Session 管理要灵活，支持主动新建/切换对话 session（每次分析可能需要独立的 session）

### 10. 向量嵌入服务

为向量检索（概念 #7）提供文本嵌入能力。

- 采用远端 API（兼容 OpenAI 标准格式）
- 不占用本地服务器算力

### 11. 网页搜索能力

分析时需要获取公开市场信息——新闻、公告、舆情等。

- 需要一个能搜索公开网页或财经舆情的 API
- 作为 LLM 分析时的外部信息来源

### 12. 行情数据源

股票日行情数据（DailyInfo）的数据来源。

- 采用腾讯财经接口获取 A 股行情
- 有频率限制：请求间隔过短会被封端口，需设计合理的轮询间隔

### 13. 舆情数据源

舆情信息的来源。

- **待决策** — 暂未确定具体数据源
- 当前设计：舆情获取作为流水线的可选环节（Stage 3），数据源确定前跳过该阶段不影响主流程
- 候选方向：公开财经新闻 API、搜索引擎 API、金融数据服务商

### 14. 输入方式

系统的操作入口分为两类：

- **CLI（命令行）** — 在服务器终端直接执行管理命令，适合脚本化和定时任务
- **OpenClaw 插件** — 打包为 OpenClaw 生态中的插件，通过 MCP 协议暴露工具，供 Claude、Cursor 等 AI 代理调用。插件的具体能力范围随开发推进逐步确定。

OpenClaw 插件开发参考文档：
- [插件清单（Manifest）规范](https://docs.openclaw.ai/zh-CN/plugins/manifest)
- [构建插件](https://docs.openclaw.ai/zh-CN/plugins/building-plugins)
- [工具插件](https://docs.openclaw.ai/plugins/tool-plugins)
- [插件设置与配置](https://docs.openclaw.ai/zh-CN/plugins/sdk-setup)
- [插件入口点](https://docs.openclaw.ai/plugins/sdk-entrypoints)
- [插件套件包（Bundles）](https://docs.openclaw.ai/zh-CN/plugins/bundles)

### 15. 输出规范：Full / Overview

所有报告类输出，统一提供两种粒度：

| 模式 | 说明 |
|------|------|
| **Full（全量）** | 完整报告，包含所有分析过程和细节 |
| **Overview（概述）** | 精简摘要，只包含结论和核心指标 |

用户在请求时可指定输出模式，不加指定则默认输出 Overview。
