# 技术选型

> 阶段：技术选型 — 确定技术栈。

## 选型结果

| 项 | 选择 | 理由 |
|------|------|------|
| 语言 | TypeScript (Node.js) | OpenClaw 插件 SDK 原生支持 |
| 数据库 | SQLite + sqlite-vec | 零配置、单文件、支持向量检索 |
| 数据访问 | Drizzle ORM | 轻量、类型安全、SQLite 原生支持 |
| CLI 框架 | Commander.js | 与 OpenClaw 保持一致 |
| 配置格式 | .env | Node.js 生态原生支持 |
| 项目结构 | monorepo（plugin / cli / server） | 职责分离，便于独立发布 |

## 数据库设计约束

### 数据库路径可配置

- 数据库文件路径通过 `.env` 配置文件指定，不打包在项目中
- 默认路径可指向项目外部的固定位置（如 `/data/fi-pool/db/`）

### 初始化而非覆盖

- 启动时按配置路径查找数据库文件
- 如果文件不存在：自动初始化一个新的空库（建表、建索引）
- 如果文件已存在：直接连接使用，**绝不覆盖已有数据**
- 版本升级时，通过 Drizzle 迁移脚本更新表结构，不动已有数据

### 启动逻辑

```
启动
  ↓
读取 .env，获取 DB_PATH
  ↓
检查 DB_PATH 指向的文件是否存在
  ├── 存在 → 直接连接，检查是否需要迁移
  └── 不存在 → 创建新数据库文件，执行建表脚本
  ↓
正常启动
```
