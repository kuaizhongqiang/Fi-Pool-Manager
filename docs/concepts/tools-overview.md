# 工具能力分类

> 阶段：概念定义 — 工具清单初稿。待逐个确认。

## 分类体系

系统的对外能力按返回特征分为五类：

| 分类 | 操作性质 | 返回值特征 |
|------|---------|-----------|
| **管理类** | 写操作 | 简单成功/失败 |
| **查询类** | 读操作 | 简单值 |
| **命令类** | 复杂操作 | 结构化结果 |
| **执行类** | 触发流程 | 待定 |
| **辅助类** | 元操作 | 帮助信息/列表/状态 |

---

## 管理类

| 工具 | 说明 |
|------|------|
| 创建股池 | 新建一个命名股池 |
| 删除股池 | 删除指定股池 |
| 修改股池 | 修改股池名称或描述 |
| 股池加股票 | 向指定股池添加一只或多只股票 |
| 股池删股票 | 从指定股池移除一只或多只股票 |
| 设置池信号 | 手动设置股池的综合信号值 |

## 查询类

| 工具 | 说明 |
|------|------|
| 查股池列表 | 返回所有股池的概要列表 |
| 查池中股票 | 返回指定股池中的股票列表 |
| 查股票信息 | 返回股票基本信息（代码、名称、当前价） |
| 查日行情 | 返回指定股票的 OHLCV 数据（可指定日期范围） |
| 查分析报告 | 返回指定股票指定日期的 DailyAnalysisReport |
| 查最终报告 | 返回指定股票指定日期的 FinalReport |
| 查系统状态 | 返回系统运行状态 |

## 命令类

| 工具 | 说明 |
|------|------|
| 输出分析报告 | 输出指定股票的 DailyAnalysisReport（支持 full/overview） |
| 输出最终报告 | 输出指定股票的 FinalReport（支持 full/overview） |
| 输出股池报告 | 输出整个股池的综合报告（支持 full/overview） |
| 语义搜索 | 基于向量检索搜索历史分析报告 |
| 管理 Session | 新建 session、切换 session、查看当前 session |

## 执行类

| 工具 | 说明 |
|------|------|
| 个股单分析 | 对单只股票运行本地分析（DailyInfo → DailyAnalysisReport，不调 LLM） |
| 个股全流水线 | 对单只股票运行完整流水线（数据 → 分析 → 多角色 → FinalReport） |
| 池子批量分析 | 对指定股池中所有股票运行指定级别的分析 |
| 池子全流水线 | 对指定股池中所有股票运行完整流水线 |
| 更新行情数据 | 触发获取最新日行情数据（可指定单只或全部） |

---

## 辅助类

| 工具 | 说明 |
|------|------|
| 帮助 | 输出命令帮助信息（--help） |
| 列出资源 | 列出可用股池、可用工具等（--list） |
| 查看状态 | 查看系统运行状态（--state） |
| 版本信息 | 输出版本号 |
| 查看配置 | 查看当前系统配置（端口、Key 状态、LLM 地址等） |
| 设置配置 | 修改配置项（端口、API Key、Token、LLM 连接地址等） |
